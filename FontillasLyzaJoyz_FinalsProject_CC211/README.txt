LYZA JOYZ FONTILLAS — PORTFOLIO WEBSITE

PROJECT FILES
- index.html: page structure and portfolio content
- style.css: design, layout, colors, typography, responsive styling
- script.js: carousel, photo upload, navigation highlighting, and login modal behavior
- assets/: extracted image files used by the page (portrait, gallery, skill and contact images)

HOW TO RUN
1. Keep index.html, style.css, script.js, and the assets folder together.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Internet access is used to load the Google Fonts referenced in style.css; the page layout and local images work without it.

NOTES
- The contacts section includes the corrected four-column layout to match the supplied reference.
- Update the phone numbers, email address, and social profile URL in index.html if needed.
- The login dialog is a front-end demonstration only; it does not authenticate users or store passwords.

Header logo: assets/logo.png (cropped from the uploaded logo reference and displayed in the header).
